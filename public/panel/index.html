客户端说明

浏览器分享文件菜单可生成 1 小时、24 小时或 7 天临时链接，仅能访问单个文件。
隐私分享链接使用密码派生的 HMAC 签名，不会把 WebDAV 密码写进 URL。

安全说明

面板与 WebDAV 共用现有 Basic Auth。密码只保存在 Worker Secret 中，不写入仓库，也不会由面板 API 返回。临时分享链接最长 7 天，并使用当前密码作为签名密钥；修改密码后旧链接自动失效。

当前边界

单用户模型、Basic Auth、无回收站。删除操作是立即删除；如果文件很重要，请在 R2 侧另做备份或版本化策略。大文件已使用 Multipart，但浏览器刷新后暂不自动恢复未完成任务。
